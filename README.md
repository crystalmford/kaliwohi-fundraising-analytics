# Kaliwohi Fundraising Analytics

A privacy-focused fundraising analytics project created to demonstrate how Salesforce and Tableau can support donor management and strategic fundraising for a tribal nonprofit organization.

## Tools Used

- Tableau Public
- Salesforce
- Microsoft Excel
- Google Colab

## Project Highlights

- Interactive fundraising dashboard
- Synthetic donor data to protect confidentiality
- Analysis of donor demographics and tribal affiliations
- Real-world nonprofit use case
